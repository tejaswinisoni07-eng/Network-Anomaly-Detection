# NETGUARD – AI-Based Anomaly Detection in Network Traffic

## Project Overview
NETGUARD is a network security dashboard designed to analyze network traffic and identify abnormal activities using AI-based anomaly detection.

The project aims to help monitor network traffic, detect suspicious activities, and display analysis results through an interactive dashboard.

## Features
- Dark-themed security dashboard
- CSV network traffic upload
- CSV data validation
- Network traffic visualization using charts
- Normal and anomaly record classification
- Search and filter detection results
- Detection statistics
- Backend API integration preparation

## Technologies Used
- HTML
- CSS
- JavaScript
- Chart.js
- Python FastAPI (Backend – planned)
- Machine Learning (planned)

## How to Run
1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Upload a valid CSV file containing network traffic records.
5. Click **Analyze Traffic** to view statistics and charts.
